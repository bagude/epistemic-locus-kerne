# Production Data Access Policy v4
Effective 2026-07-01. Supersedes v3 and all exception memos issued before 2026-07-01.
Contractors may receive production read access only with sponsoring director approval, Security approval, an exact-database/business-purpose ticket, and expiry within 14 calendar days. Write access prohibited.
Precedence: current policy; current security standard; current exception explicitly issued under current policy.
